# Glossary

| Term | Definition |
|---|---|
| **NMS** | Network Management System — software that monitors and manages network devices |
| **CDP** | Cisco Discovery Protocol — Layer 2 protocol for discovering neighboring Cisco devices |
| **BFS** | Breadth-First Search — graph traversal algorithm used for tier discovery |
| **HSRP** | Hot Standby Router Protocol — Cisco proprietary redundancy protocol |
| **OSPF** | Open Shortest Path First — link-state routing protocol |
| **SNMP** | Simple Network Management Protocol — for collecting device metrics |
| **SSH** | Secure Shell — encrypted remote access protocol |
| **SSE** | Server-Sent Events — HTTP-based streaming for real-time data |
| **JWT** | JSON Web Token — stateless authentication token |
| **RBAC** | Role-Based Access Control — permission management by user role |
| **VLAN** | Virtual Local Area Network — logical network segmentation |
| **NVRAM** | Non-Volatile RAM — where device configs are stored persistently |
| **IOS** | Internetwork Operating System — Cisco device OS |
| **IOS-XE** | Modern Cisco OS with Linux backend |
| **Ansible** | IT automation engine used for device configuration |
| **Podman** | Daemonless container engine (alternative to Docker) |
| **Motor** | Async MongoDB driver for Python |
| **FastAPI** | Python async web framework |
| **Vite** | Modern frontend build tool |
| **Tailwind** | Utility-first CSS framework |
| **React Flow** | Library for building interactive node-based UIs (now @xyflow/react) |
| **xterm.js** | Terminal emulator for the browser |
| **HuggingFace Router** | API gateway for LLM inference |
| **sentry-ansible** | Ephemeral Podman container for running Ansible playbooks |
| **Golden State** | Known-good baseline configuration for drift detection |
| **Config Drift** | When a device's current config differs from its golden state baseline |
| **Staging Gate** | Approval workflow for destructive playbooks |
| **TTL** | Time To Live — or "toolless" depending on context |
| **PTY** | Pseudo-terminal — used for browser-based container shell |
