# Configuration Reference

## Environment variables

Loaded from `watchman/.env` (volume-mounted to `/app/.env` in the container).

| Variable | Required | Default | Used in | Purpose |
|---|---|---|---|---|
| `DB_USER` | Yes | — | `config.py:19` | MongoDB Atlas username |
| `DB_PASS` | Yes | — | `config.py:20` | MongoDB Atlas password |
| `DB_HOST` | Yes | — | `config.py:21` | MongoDB Atlas hostname |
| `SECRET_KEY` | Yes | — | `config.py:39` | JWT signing secret |
| `HUGGINGFACE_API_KEY` | For AI | — | `llm_routes.py:21` | HuggingFace Router API token |
| `MONGO_URI` | No | computed from DB_* | `database.py:13` | Override MongoDB URI (e.g., for local vault) |

## API base URL (frontend)

Set `VITE_API_BASE_URL` in `frontend/.env` or as an env var at build time.

| Value | Environment | Effect |
|---|---|---|
| (unset) | Dev | Defaults to `http://127.0.0.1:8000` |
| `http://localhost:8000` | Dev | Standard dev API |
| `http://<host>:8000` | Networked dev | Cross-machine access |
| (unset) | Prod build | Falls back to `http://127.0.0.1:8000` — **must** be set for production |

## Ansible configuration

**File:** `watchman/ansible.cfg`

```ini
[defaults]
host_key_checking = False
```

**Inventory:** `watchman/playbooks/hosts.ini` — generated by setup wizard.

## Podman storage

Configured in `watchman/Dockerfile:7-9`:
```ini
[storage]
driver = "vfs"
runroot = "/run/containers/storage"
graphroot = "/var/lib/containers/storage"
```

Uses VFS driver (overlay is unavailable inside the watchman container).
